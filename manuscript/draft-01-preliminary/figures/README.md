files in `../figure-source/`.

Each figure is exported as PNG, PDF, and SVG. All are preliminary and must be
regenerated after the cohort, statistical models, and result tables are frozen.

data. It requires genomic coordinates, orientation, read support, effect sizes,
and per-sample expression from the authoritative output package.
